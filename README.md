# A Nominal Formalization of the Confluence of a Calculus with Explicit Substitutions via the Z Property

This repository contains a formalization in the [Rocq Prover](https://rocq-prover.org) of the confluence of the λx-calculus, an extension of the λ-calculus with explicit substitutions. The proof uses the compositional Z property and a nominal representation of terms (named variables, with α-equivalence defined via swaps).

The main result is

```coq
Theorem lambda_x_is_confluent: Confl lambdax.
```

in [`src/lx_nom.v`](src/lx_nom.v).

The Rocq files are written in a literate style: the coqdoc comments in them are the text of the paper *A Nominal Formalization of the Confluence of a Calculus with Explicit Substitutions via the Z Property* (SBMF 2026), which is generated from them.

## Repository structure

```
.
├── _RocqProject          Rocq project file (logical paths LXConfl and Metalib)
├── Makefile              Builds the formalization and the paper
├── src/                  Rocq sources
│   ├── infra_nom.v       Terms with explicit substitutions (n_sexp), swaps, free variables
│   ├── aeq_equiv_es.v    α-equivalence and its properties (equivalence, stability under swaps)
│   ├── msubst.v          Metasubstitution and its properties (incl. the Substitution Lemma)
│   ├── ZtoConfl_nom.v    Z property and compositional Z property modulo α, and confluence
│   ├── lx_nom.v          The λx-calculus and its confluence proof
│   └── Metalib/          Copy of the Metalib library (atoms, finite sets, tactics)
├── latex/                The paper
│   ├── sbmf2026.tex      Main LaTeX file (includes the generated *.v.tex files)
│   ├── report.bib        Bibliography
│   ├── llncs.cls, splncs04.bst   Springer LNCS class and bibliography style
│   ├── coqdoc.sty        Style file for the coqdoc output (regenerated by rocq doc)
│   └── rocq-logo-white.pdf       Rocq logo shown on the code boxes
└── tools/                Helper scripts used by `make doc`
    ├── glob2links.py     Maps each Rocq definition to its line in the source,
    │                     so that the code boxes in the PDF link to the repository
    └── tidy_coqdoc.py    Cleans up the rocq doc output (removes empty code blocks
                          and tells each code box which definition it shows)
```

The files depend on each other as follows:

```
infra_nom ── aeq_equiv_es ──┬── msubst ────────┐
                            └── ZtoConfl_nom ──┴── lx_nom
```

## Requirements

- [Rocq Prover](https://rocq-prover.org) 9.1.1 (`rocq-core`) and its standard library (`rocq-stdlib`). With [opam](https://opam.ocaml.org):

  ```sh
  opam install rocq-core.9.1.1 rocq-stdlib
  ```

## Compiling the formalization

```sh
make
```

This generates `CoqMakefile` from `_RocqProject` and compiles all the files in `src/` (including `Metalib`). A file can also be compiled on its own, together with its dependencies, e.g. `make src/lx_nom.vo`.

## Building the paper

- To build the paper: a LaTeX distribution with `pdflatex` and `bibtex` (e.g. TeX Live,
  including the `tcolorbox`, `mathpartir`, `xypic` and `hyperref` packages), Python 3
  and Git.

```sh
make doc
```

This compiles the formalization if needed, runs `rocq doc` on the files in `src/` to produce the `latex/*.v.tex` fragments, and then runs `pdflatex` and `bibtex` to produce `latex/sbmf2026.pdf`. `make pdf` opens the result with `evince`.

## Cleaning

```sh
make clean-doc   # removes the generated LaTeX files and LaTeX auxiliary files
make clean       # also removes the compiled Rocq files and CoqMakefile
```
